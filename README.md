# SubjectDraw

![SubjectDraw](icon.png)

AI 驱动的知识卡片排版工具 — 交作业神器

## 一句话介绍

告诉 AI 你想做什么作业，SubjectDraw 帮你把 AI 返回的内容变成漂亮的知识卡片。

## 核心功能

### 三步完成作业

1. **生成提示词** — 选学科、选主题、选格式，一键生成专业提示词
2. **粘贴到 AI** — 把提示词发给 ChatGPT / Claude / Kimi 等任意 AI
3. **生成预览** — 把 AI 返回的 JSON 粘贴进来，瞬间生成精美知识卡片

### 4 种输出格式

| 格式 | 适用场景 |
|------|----------|
| **思维导图** | 概念梳理、知识点关系、复习总结 |
| **表格** | 对比分析、分类整理、特征归纳 |
| **时间轴** | 历史事件、发展进程、年表整理 |
| **大纲** | 课本笔记、知识框架、层级结构 |

### 思维导图交互操作

- **拖拽卡片** — 按住鼠标左键自由拖动任意卡片
- **缩放平移** — 鼠标滚轮缩放，拖拽空白区域平移
- **右键菜单** — 右键点击分支/要点/中心卡片，可编辑文字、高光标记、反转方向、添加要点、删除等
- **自定义颜色** — 输入框 + 色块调色盘，选一个颜色自动生成主题
- **中心位置** — 5 种布局：居中 / 左侧 / 右侧 / 上方 / 下方
- **反转方向** — 右键选择反转方向，只移动要点到另一侧，分支标题不动
- **拖拽换边** — 拖动卡片越过中心时，连接线自动切换到正确的一侧

### 5 种装饰风格

简约几何、中式古典、自然花藤、学术边框、默认

### 知识面板

每张卡片底部自动生成：
- **核心概念** — 术语 + 准确定义
- **关键人物** — 姓名 + 身份 + 贡献
- **知识拓展** — 补充说明与背景知识

### 学生信息栏

顶部显示：学科、姓名、班级、学号、日期

### 使用教程

侧边栏内置使用教程，点击即可查看完整操作指南

## 产品特色

- **零依赖** — 纯 Python 标准库，无需安装任何第三方包
- **开箱即用** — 下载 exe 双击运行，无需配置环境
- **AI 无关** — 支持 ChatGPT、Claude、Kimi、文心一言等任意 AI
- **插件架构** — `formats/` 目录下每个子文件夹 = 一种新格式，开发者可自由扩展

## 快速开始

```bash
# GUI 模式（推荐）
python gui.py

# CLI 模式
python app.py --json subjects/历史/辛亥革命.json --format 思维导图

# 指定风格
python app.py --json subjects/历史/辛亥革命.json --format 表格 --style 中式古典

# 带学生信息
python app.py --json subjects/历史/辛亥革命.json --name 张三 --class "七年级1班" --sid "001"
```

## 项目结构

```
SubjectDraw/
├── app.py                  # CLI 入口
├── gui.py                  # GUI 入口（侧边栏 + 预览 + 设置）
├── config.py               # 全局配置
├── core/
│   ├── theme.py            # 色彩主题
│   ├── gui_themes.py       # GUI 界面主题
│   ├── prompts.py          # 提示词模板
│   ├── decorations.py      # 装饰风格 + 知识面板
│   └── format_manager.py   # 插件发现/加载
├── formats/
│   ├── 思维导图/            # 思维导图渲染器（含拖拽/缩放/右键菜单）
│   ├── 表格/
│   ├── 时间轴/
│   └── 大纲/
└── subjects/               # 知识库 JSON 数据
```

## 插件开发

在 `formats/` 下新建文件夹，包含两个文件即可：

```
formats/你的格式/
├── prompt.md      # 提示词模板（AI 生成 JSON 的格式要求）
└── renderer.py    # 渲染器，导出 render_html(data, **fmt_opts)
```
